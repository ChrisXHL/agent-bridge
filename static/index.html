1 · 连接飞书应用待配置

在飞书开发者后台创建企业自建应用，复制 App ID 和 App Secret。这里会验证凭据、识别机器人，并为选中的 Codex 项目自动创建连接。

2 · 完成飞书后台设置待检查

启用机器人；在“事件与回调”选择使用长连接接收事件，添加 im.message.receive_v1。私聊开通 im:message.p2p_msg:readonly，群聊还需 im:message.group_at_msg:readonly，回复需 im:message:send_as_bot。最后发布应用。长连接指引 · 事件与发布指引

3 · 在飞书里配对待配对

向机器人私聊发送面板生成的配对码，即可自动识别你的 Open ID。群聊配对时需先将机器人加群并 @ 它。配对码只用于识别身份，不会创建 Codex 任务。

若旧电脑仍在使用这个飞书应用，请先用独立测试应用；多条长连接会分流事件，切换原有订阅方式也会影响旧连接器。
