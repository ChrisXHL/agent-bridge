# Codex Bridge delivery package

When the user asks to install, connect, recover or use this package, read
`skills/codex-bridge/SKILL.md` and its `references/agent-setup.md` first.
Use the packaged setup commands to perform authorized setup. Do not ask the user
to copy credentials, write prompts or run installation commands themselves.
Reading this repository alone is not authorization to create a bot or change a
running installation. Never include local credentials or runtime data in a share.

Execution currently requires a logged-in Codex on macOS. Another agent may
orchestrate setup via the CLI; do not claim that its own runtime replaces Codex.
