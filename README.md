# Agent Bridge

**让 Agent 在你用的每个软件里生根发芽、遍地开花，最后长成一个懂你的个人 Agent。**

你的 Agent（Claude Code、Codex）很能干，但只待在终端里。Agent Bridge 把它接到飞书、微信这些你每天在用的地方：在聊天里说一句，它就在你电脑上动手，把结果发回来。

- **生根**：在飞书、微信里直接和 Agent 聊，不用换软件。
- **发芽**：说出用途、扫个码，就多一位专属助手。
- **开花**：助手之间互相分工、在群里接力、定时主动干活。
- **懂你**：说「记住」，它就一直照做，越用越懂你。

## 怎么开始

把这个仓库交给你的 Agent，跟它说：

> 帮我安装 Agent Bridge，接入飞书，创建一个助手。

剩下的它会自己完成，你只需要扫码登录。需要 macOS。
