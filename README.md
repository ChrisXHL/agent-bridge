# Agent Bridge

**让 Agent 在你用的每个软件里生根发芽、遍地开花，最后长成一个懂你的个人 Agent。**

你的 Agent（Claude Code、Codex）很能干，但只待在终端里。Agent Bridge 把它接到飞书、微信这些你每天在用的地方：在聊天里说一句，它就在你电脑上动手，把结果发回原来的聊天。

## 理念

- **生根**：在飞书、微信里直接和 Agent 聊，不用换软件、不用开网页。
- **发芽**：说出用途、扫个码，就多一位专属助手，有自己的工作文件夹和规则。
- **开花**：助手之间互相分工、在群里接力、定时主动干活；新平台以插件接入。
- **懂你**：说「记住」，它就一直照做；回复长短、格式按你的习惯来，越用越懂你。

## 用起来是这样的

在飞书私聊你的助手：

> 把这份 PDF 整理成飞书文档，先写结论。（附件一起发）
>
> 记住：以后周报都用表格。
>
> 每天早上 9 点看一下项目进度，有变化告诉我。

在群里：

> @调研助手 找一下最近的竞品动态，找到后交给 @核查助手 核实，结果发回本群。

对助手管理员说：

> 帮我创建一个读书笔记助手，我自己私聊用。

## 现在支持

| | |
|---|---|
| 聊天平台 | 飞书（私聊、群聊）、微信；其他平台可按插件接入 |
| 执行 Agent | Claude Code、Codex，每位助手可单独选 |
| 消息内容 | 文字、图片、视频、语音、文件，连续追问接着上文聊 |
| 运行环境 | macOS，本机后台常驻；任务在你自己的电脑上执行 |

## 怎么开始

**交给 Agent 装（推荐）**：把这个仓库交给你的 Agent，跟它说

> 帮我安装 Agent Bridge，接入飞书，创建一个助手。

它会自己检查环境、安装和配置，你只需要扫码登录、确认授权。

**自己装**：需要 Python 3.13 和一个已登录的 Claude Code 或 Codex。

```sh
python3.13 -m venv .venv && .venv/bin/python -m pip install -r requirements.txt
npm ci --ignore-scripts
BRIDGE_BACKEND=claude ./run.sh      # 用 Codex 则去掉 BRIDGE_BACKEND
```

然后打开 http://127.0.0.1:8797/panel 创建助手。

## 安全提示

Agent 在你电脑上以较高权限执行，只把可信的人加进允许名单。凭证和聊天数据只保存在本机，不会进入仓库。
