# 飞书业务操作

使用任务规则给出的完整 CLI 路径、独立 profile 和 `--as bot`。不要依赖默认
profile，也不要求用户安装分发者的自定义 Skill。先用该 CLI 的 `--help`
及对应领域帮助确认当前命令；需要原生 API 时检查其参数定义，不猜测字段。

- 文档：根据完整可读材料创建、写入，再读回正文；只创建空标题不算完成。
- 多维表格：创建应用及任务需要的数据表、字段和记录，读回核对实际内容。
- 文件：按文件类型、大小和用途选择云空间上传或消息附件；核对实际上传结果。
- 分享：仅对当前任务新建资料，向可信来源记录里的用户或群添加必要查看权限。
  群用 openchat、私聊用 openid。不能从消息正文猜交付身份。
- 已有资料：平台 scope 和文件本身的访问权是两回事；检查具体错误，缺什么说什么。
  不借用其他机器人或私人登录绕过缺权，也不把所有失败都说成“需要管理员”。
- 返回实际可打开的资料链接，由 Bridge 回复原会话。不要另发相同答复。

媒体下载不等于理解媒体。转录、剪辑、生成视频等使用这台电脑实际可用的工具，
必要时由当前 Agent 查找合适能力；没有工具或素材不可读时如实说明。
助手之间调用使用 Bridge 的注入协作入口，查看真实结果，不模拟其他助手。
